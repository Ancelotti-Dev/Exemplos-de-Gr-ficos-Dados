### 💡 Nome do Projeto
`Exemplos de Gráficos - Análise de Dados com Python`

---

### 📝 Descrição

Este repositório apresenta exemplos de visualizações gráficas criadas com **Python**, utilizando bibliotecas como **Pandas**, **Matplotlib** e **Seaborn**. O objetivo é demonstrar como explorar dados e gerar gráficos de forma simples e eficiente, facilitando a análise estatística e tomada de decisões com base em dados reais.

---

### 📊 Tecnologias utilizadas

- Python 3.13  
- Pandas  
- Seaborn  
- Matplotlib  
- Jupyter Notebook (opcional)

---

### 📁 Arquivos

- `Dados.py` → Script com os códigos de visualização  
- `ecommerce_estatistica.csv` → Base de dados utilizada para os gráficos

---

### 📈 Exemplos de gráficos gerados

- Histogramas
- Gráficos de Densidade (KDE)
- Gráficos de Dispersão (Scatter Plot)
- Mapas de Calor
- Personalização de cores com `rocket_r`, `plasma`, etc

---

### 🚀 Como executar o projeto

1. Clone o repositório:

```bash
git clone https://github.com/Ancelotti-Dev/Exemplos-de-Gr-ficos-Dados.git
```

2. Instale os pacotes necessários:

```bash
pip install pandas matplotlib seaborn
```

3. Execute o script:

```bash
python Dados.py
```
